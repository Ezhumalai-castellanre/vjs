  → Choose "Shared" (M0 FREE)
  → Select closest region
  → Click "Create Cluster"
  → Wait 3-5 minutes

  → Username: vjkadmin
  → Click "Autogenerate Secure Password"
  → 💾 SAVE PASSWORD!

  Password: ________________

□ STEP 4: NETWORK ACCESS (1 min)
  → Add IP Address: 0.0.0.0/0
  → Description: "Allow from anywhere"
  → Click "Add Entry"

□ STEP 5: GET CONNECTION STRING (1 min)
  → Click "Connect" button
  → Choose "Drivers"
  → Copy connection string
  → Replace <password> with your actual password
  
  Your connection string:
  mongodb+srv://vjkadmin:YOUR_PASSWORD@cluster0.xxxxx.mongodb.net/...

□ STEP 6: TEST LOCALLY (Optional)
  → Update server/.env with connection string
  → Set USE_FILE_DB=false
  → Restart server: cd server && npm start
  → Should see: "✅ Connected to MongoDB"

□ STEP 7: VERIFY DATA

  → Click "Browse Collections"
